## 当前限制与后续整改

1. 零长度 UDP 报文保留在 JSONL，但当前 byte-based ACK 展示流跳过这类条目。
2. Server 部分广播失败保留逐客户端结果， aggregate TX 计数未累计成功子集；完整成功累计全部本地 accepted bytes。
3. 串口不具备唯一序列号时，自动重连拒绝；需人工确认并打开。
4. 录制高水位未对 TCP 实施 pause/resume；达到全局硬上限停止录制并明确标记不完整，不保证超载无损。
5. 配置写入有读取比对/确认，但不是跨进程 CAS；确认后的极短时间外部竞态尚需进一步处理。
6. 展示单条截断到 256 字节；完整载荷只保留在原始日志，不能把展示当作完整导出。
7. 配置路径不可访问时会报错；不支持远程设备通信、IPv6、组播。
8. 未实现 CRC/Parser/Plot、MQTT/Modbus/CAN/BLE，这些属于原技术表后续 P2 版本。

以上限制未全部满足原技术表严格验收标准，不将 T01～T37 一律标记为“已完成”。
下一轮优先真实 Extension Host 集成验证、发送部分结果计数、日志高水位背压与长期压力测试。
