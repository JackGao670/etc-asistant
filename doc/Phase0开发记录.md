## 2. 已实现内容

| 内容 | 实现与边界 |
| --- | --- |
| 扩展入口 | 本地 UI Host、5 个原型命令、受限工作区通信检查、停用清理 |
| 运行位置诊断 | 显示实际 VS Code/Node/Node-API/平台/主机/remoteName；通过 workspace.fs 查询项目 URI |
| 串口探针 | SerialPort 延迟加载、枚举、手动路径、波特率、8N1、复位风险确认、接收摘要、可选单次 HEX 发送 |
| TCP 数据管线 | 本地回环、1 MiB/s 生成流、有界展示缓存、JSONL 原始录制、SHA-256 完整性对比 |
| Webview 批次探针 | CSP/nonce、真实 base64 消息与 DOM/ACK、每批 64 KiB、最多 4 批未确认、ACK 超时/隐藏/关闭结束；运行指标待验证 |
| 数据编码 | 严格 HEX/7-bit ASCII、输入和原始载荷上限 |
| 测试与打包 | TypeScript 检查、Node.js test runner/tsx、esbuild、扩展宿主冒烟脚本、Windows x64 VSIX 和原生产物检查 |

串口探针不是完整 Transport：原生 open 无法强行中止，停止请求或超时后关闭晚到的结果。
TCP 管线仅用于风险验证，不具备生产录制轮转/恢复和全部生命周期能力。
TCP 管线批次仍为模拟聚合。新增独立 Webview 探针用于实际 DOM/ACK，
尚未取得宿主运行结果，不包含 React 绘制或完整 TCP→UI 延迟认证。
